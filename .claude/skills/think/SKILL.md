# /think: deep strategic analysis

OS home: `C:\Users\tom.otieno\Desktop\OS`. Outside that folder, read `AGENTS.md` and `registry/ROUTES.md` there first.

Request: $ARGUMENTS

Skills: the `/think` row of `registry/ROUTES.md`. For a long analysis, hand it to the `strategist` agent.

## Method

1. **Frame.** State the question, the decision it serves, which venture it touches and the time horizon. If the decision is unclear, ask once.
2. **Ground.** Pull what is already known: `knowledge/DECISIONS.md`, `knowledge/LESSONS.md`, `portfolio/PROJECTS.md` and the project's own files. Label every assumption as an assumption.
3. **Analyse.** Drivers, constraints, second-order effects, what competitors or partners would do, and the main risks.
4. **Wildcard.** Take one deliberate pass at a counter-intuitive option and label it "Wildcard". Tom decides whether to use it.
5. **Pressure-test.** Name the one to three facts that would flip the conclusion, and how to check each.

## Deliver

- The bottom line first, in two or three sentences.
- The reasoning, then the assumptions, the Wildcard and the facts that would change your mind.
- One next step. Suggest `/research` for evidence gaps and `/decide` if a choice is now due.
