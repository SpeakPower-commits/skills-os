# Repurposing Matrix

Reference this when building Step 5 (repurposing map) of the main pipeline. Match format to platform norms — don't reuse one aspect ratio/length everywhere.

| Source | Output | Aspect | Length | Notes |
|---|---|---|---|---|
| Documentary / long ad | YouTube long-form | 16:9 | 3–15 min | Full narrative arc, chapter markers in description |
| Documentary / long ad | Vertical cutdowns (Reels/Shorts/TikTok) | 9:16 | 15–60s | Hook in first 1.5s, captions burned in, one idea per cutdown |
| Documentary / long ad | LinkedIn cutdown | 1:1 or 4:5 | 30–90s | More narration-forward, less meme-pace than TikTok |
| Podcast episode | Audiogram clips | 1:1 or 9:16 | 30–60s | Waveform + captions, pull the single sharpest quote |
| Podcast episode | Show notes / blog | — | 800–1500 words | Built from transcript, structured for AEO (see seo-aeo-checklist.md) |
| Podcast episode | Newsletter segment | — | 150–300 words | One insight + link back to full episode |
| Talking-head ad | Static/carousel ad | 1:1 or 4:5 | — | Pull key frame + on-screen text as a Canva static fallback for placements that don't support video |
| Any video | Transcript-based FAQ page | — | — | Question-and-answer chunks pulled from the transcript, framed for AI-answer-engine retrieval |

## Platform hook conventions
- **TikTok/Reels/Shorts**: cold open on the payoff or the conflict, no logo/title card intro
- **YouTube**: retain a short branded intro if channel consistency matters more than immediate retention (weigh against watch-time data if available)
- **LinkedIn**: native upload outperforms external links; captions on by default (assume sound-off viewing)
- **Podcast directories**: title + first line of description do the discovery work — front-load the specific outcome/topic, not the guest's name alone
