## Method

1. **Load the map.** Read `portfolio/PROJECTS.md`, `knowledge/DECISIONS.md` and `knowledge/LESSONS.md` in the OS home. Open a project folder only when a specific opportunity needs checking.
2. **Scan for five patterns:**

3. **Evidence each opportunity**: the projects involved, the proof, the value, the effort and the first step.
